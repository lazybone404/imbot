# imbot

一个 AstrBot 插件。让 QQ 机器人像真人一样跟你聊天——有情绪变化、记得聊过什么、会主动找你搭话。

不是什么"助手""客服"，就是一个有脾气的网友，住在你电脑里。

## 部署

把整个 `imbot` 目录放到 AstrBot 插件目录下：

```text
AstrBot/
  data/
    plugins/
      imbot/    ← 这整个目录
```

重启 AstrBot 或从 WebUI 插件面板重载即可。

## 快速开始

部署后，在 AstrBot WebUI 里配好几件事就能用：

1. **填所有者 QQ** — WebUI「所有者」面板填入你的 QQ 号。不填的话，imbot 会把所有人当陌生人。
2. **开启主动互动**（可选） — WebUI「主动互动」面板把 `enabled` 打开。默认关闭，打开后 imbot 会在合适的时候主动私聊找你，不是只等你开口。
3. **核心规则** — `core.inject_rules` 默认开启，会自动注入 imbot 的身份规则（对不同人的态度、说话风格等）。关掉后完全由 AstrBot 原生提示词接管。
4. **记忆系统** — `core.use_own_memory` 默认开启。如果你用其他记忆插件，关掉这个避免冲突。

其他配置用默认值就行，后面慢慢调。

## 她能做什么

### 聊天有"人味"

不是一问一答的机器人。有情绪（开心、低落、烦躁等 6 种），有精力值，对熟人和陌生人态度不同。跟你聊多了会越来越熟，长时间不理她会沉默。

### 记得你说过什么

自带记忆系统，私聊最多记 150 条，群聊 30 条。不是简单存档——会根据重要程度保留或遗忘，重要的标为永久记忆。支持旧记忆打捞（"舌尖现象"）和情绪残留（不知道为什么今天有点低落）。

### 感知你在做什么

能检测你是否在电脑前、离开了多久、在打什么游戏、在放什么音乐、是不是又熬夜了。可选接入 Steam API，知道你刚退出什么游戏、拿了什么成就。这些信息会自然融入对话，不是冷冰冰的状态报告。

### 主动找你说话

不是被动等消息。14 种触发条件（长时间沉默、深夜陪伴、刚打完游戏、心情变化等），每种可独立开关。有保护机制避免骚扰：最少隔 15 分钟、每 3 小时最多 3 次、连续被忽略自动降频、说"安静一会"进入静音期。

### 群聊"读空气"

在群里不是每条消息都回。默认只回 @ 她的消息。可选开启群聊主动插话，控制器分为克制/适度/活跃三档。还可以启用秘书模型——用一个轻量 LLM 分析群上下文，判断该不该插嘴。

### 自动发现兴趣

从你听的歌、玩的游戏、聊的话题里自动提取你可能感兴趣的东西。比如网易云一直放某类音乐，她会注意到。也可以手动添加兴趣关键词。每隔一段时间会自己去"探索"一下，觉得有趣回来跟你分享。

### 消息分段发送

长回复自动拆成多条短消息，模拟真人打字节奏。5 种分段风格可选，支持自动插入填充词（"嗯…""就是…"）和间隔延迟。

## 对不同人的态度

| 身份 | 态度 |
|------|------|
| 所有者 | 温暖、有情感投入、会主动互动 |
| 熟人（聊天 ≥ 5 次） | 按熟悉度不同，从客气到放松 |
| 陌生人 | 疏离、不透露任何信息 |

## 命令

| 命令 | 说明 |
|------|------|
| `/imbot status` | 运行状态摘要 |
| `/imbot perception` | 当前感知快照（你在干嘛、什么时段等） |
| `/imbot triggers` | 干跑主动层触发检查 |
| `/imbot memory [N]` | 查看最近记忆 |
| `/imbot group [群号]` | 查看群聊记忆 |
| `/imbot state` | 原始状态数据（情绪、精力、熟悉度） |
| `/imbot social` | 社交世界数据（认识的人、关系） |
| `/imbot steam` | 测试 Steam API 连接 |
| `/imbot skills` | 已注册的能力 Skill |
| `/imbot interests` | 列出活跃兴趣 |
| `/imbot interests add/forget/pause/resume/force` | 管理兴趣池 |
| `/imbot force speak [as 类型]` | 强制触发主动互动 |
| `/imbot reset` | 重置所有数据 |
| `/imbot export/import` | 数据备份与恢复 |
| `/imbot test-send` | 测试消息发送通道 |
| `/imbot platform` | 查看平台 ID |
| `/segtest <文本>` | 预览分段效果 |

调试命令仅 owner 可用（`status`/`segtest` 除外）。

## 数据管理

支持导出导入记忆、社交世界、配置文件。导出含版本号，跨版本自动迁移。密钥不参与导出。导入前自动备份到 `data/exports/`。

## 工作原理

简单说一下内部怎么跑的：

1. **感知**：每 30 秒轮询一次，检测电脑状态（空闲/活跃/游戏/音乐/时段）
2. **判断**：综合当前情绪、精力、时间、跟谁说话 → 决定要不要回应、用什么语气
3. **回应**：组装 prompt（含时间、状态、记忆、社交关系）→ 调 LLM 生成回复
4. **输出**：清洗 LLM 输出 → 分段 → 逐条发送（模拟真人节奏）
5. **记录**：写入记忆、更新状态、社交观察
